\section{Limitations}
\label{sec:limitations}

\begin{itemize}
  \item \textbf{Eight devices, one host.} The GPU results are a single
    NVLink node and the TPU results a single v5e host. Scaling past the host
    boundary (multi-host, 32--64 chips) is designed for and untested;
    it is the natural follow-up.
  \item \textbf{The systems workload is a simplified block.} The
    scaling and cost grids benchmark one synthetic transformer block
    (square matrices, $d_{\mathrm{ff}}{=}d$, single head, no learned
    norms, MSE loss, batch 8, sequence 32; Section~\ref{sec:setup}), not
    a real transformer. The simplifications change arithmetic
    intensity and memory in ways that favor clean attribution over
    realism; absolute ratios, the low-rank advantage included, should be
    read as properties of this workload. Two real-model anchors bound
    the risk: the accuracy chain of Section~\ref{sec:endtoend}, and the
    contraction crossover re-measured on the real model with both
    signs intact (Table~\ref{tab:tb5}).
  \item \textbf{Models must adopt the library's seams.} Perturbation as
    substitution requires routing parameterized matmuls and embedding
    lookups through \texttt{shardes.nn}; an existing model does not run
    unmodified, and layer types without a seam (convolutions, for one)
    are unsupported until one is written. This is the API cost of never
    materializing the low-rank noise (Section~\ref{sec:design}).
  \item \textbf{Crossover at sweep resolution.} The (N, d) grid behind
    Figure~\ref{fig:f2} is $3\times2$ per platform with holes at the memory
    ceiling; the contour's position is bracketed, not traced.
  \item \textbf{Absolute numbers are per-platform.} A v5e chip has 16\,GB
    against the A100's 80; population ceilings therefore differ by design,
    and no absolute throughput here matches EGGROLL's H100 figures
    \citep{eggroll2025}. The
    mechanisms are argued to transfer; the scaling behaviour itself has
    been shown only at the scales measured here.
  \item \textbf{One compiler workaround ships in the library.} Rank-1
    factors carry a zero-column pad so the TPU compiler keeps them in a
    fused matrix multiply; its measured numerical footprint and its
    regression check are documented in the repository.
  \item \textbf{Barrier numbers are ceilings.} The shaping-barrier
    measurement times the barrier in isolation; a real generation may
    overlap part of that latency behind compute.
  \item \textbf{Task validation is one task, one training model size.}
    Countdown with a 0.5B-parameter model, three seeds; the flat-rank
    result is predicted and measured at $N{=}30$ and says nothing about
    larger populations. The estimator accuracy chain now spans two model
    sizes (0.5B and 1.5B), but no training run does.
  \item \textbf{The stability experiment is one task, one horizon, one RL
    recipe.} The stability experiment perturbs published settings on a
    rule-based verifier for
    150 steps; its ablation arms show the KL anchor and clip are not
    individually load-bearing \emph{there}, which says nothing about
    learned or hackable rewards, longer horizons, or critic-based methods.
    The drift cost of ES's tolerance is measured and reported in the same
    table.
\end{itemize}
